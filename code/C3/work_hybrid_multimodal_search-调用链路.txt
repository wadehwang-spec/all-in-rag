模式4: 混合检索 (RRF融合)
text
searcher.search(query_image_path, query_text, mode="hybrid", top_k=3)
  │
  ├─→ encoder.encode_text_hybrid(query_text)
  │     └─→ bge_m3([query_text]) → {sparse, dense}
  │           ├─→ 提取 dense[0] (密集向量)
  │           └─→ 提取 sparse._getrow(0) (稀疏向量)
  │
  ├─→ 创建搜索请求
  │     ├─→ dense_req = AnnSearchRequest([dense_vec], "text_dense_vector", ...)
  │     └─→ sparse_req = AnnSearchRequest([sparse_vec], "text_sparse_vector", ...)
  │
  ├─→ 创建RRF融合器
  │     └─→ rerank = RRFRanker(k=60)
  │
  ├─→ collection.hybrid_search(
  │     [sparse_req, dense_req],
  │     rerank=rerank,
  │     limit=top_k,
  │     output_fields=[...]
  │   )
  │     │
  │     └─→ Milvus执行并行搜索 + RRF重排序 → 返回融合结果
  │
  └─→ 返回 results

📋 完整数据流总结
数据准备阶段的数据流
text
JSON元数据
  → DragonImage对象
  → get_text_content()
  → encode_multimodal() + encode_text_hybrid()
  → 三种向量 (多模态/密集/稀疏)
  → Milvus Collection (标量+向量)
  → 创建索引
  → 加载到内存
用户查询阶段的数据流
text
用户输入 (图像+文本)
  ↓
根据模式选择编码方式
  ├─ 多模态: Visual-BGE → 查询向量
  ├─ 密集: BGE-M3 → 密集查询向量
  ├─ 稀疏: BGE-M3 → 稀疏查询向量
  └─ 混合: BGE-M3 → 密集+稀疏查询向量
  ↓
Milvus向量检索 (ANN/Hybrid Search)
  ↓
返回Top-K结果 (带距离分数)
  ↓
可视化展示 (对比全景图)
🎯 关键方法依赖关系
方法	依赖	作用
DragonDataset._load_metadata()	JSON文件	加载元数据
DragonDataset.get_text_content()	DragonImage字段	组装文本描述
HybridMultimodalEncoder.encode_multimodal()	Visual-BGE模型	生成多模态向量
HybridMultimodalEncoder.encode_text_hybrid()	BGE-M3模型	生成稀疏+密集向量
HybridMultimodalSearcher.create_collection()	Milvus连接	创建集合和索引
HybridMultimodalSearcher.insert_data()	编码器+数据集	批量插入向量
HybridMultimodalSearcher.search()	编码器+Milvus	执行检索
visualize_results()	OpenCV+PIL	生成可视化结果
这个调用链路清晰地展示了从数据准备到用户查询的完整流程，每个步骤都职责分明，模块之间通过明确的接口交互。
